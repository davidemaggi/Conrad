# Conrad V1 Implementation Plan

> Short-form plan by user request. Spec: `docs/superpowers/specs/2026-11-21-conrad-design.md`. Executed inline, TDD per package, commit per milestone.

**Goal:** Ship Conrad V1: a private CA with a multi-issuer ACME server, an embedded React UI, notifications, OIDC and PKCS#11.
**Stack:** Go 1.25, chi, modernc sqlite, go-jose v4, React 19 + Vite + TS + Tailwind v4 + shadcn/ui + react-i18next + TanStack Router/Query.

## Global constraints
- Module path `github.com/davidemaggi/conrad`. No CGO except the `pkcs11` build tag.
- English is the default and fallback language; `it` ships. Every locale must have the same keys as `en`.
- Leaf certificates default to 90 days, maximum 397. Root P-384 / 10 years; issuers P-256 / 5 years.
- `/acme` is an alias of the default issuer's `/acme/{slug}`.
- UI meets WCAG AA; light/dark/system themes with no flash on load.

## M1: Foundation
Files: `go.mod`, `cmd/conrad/main.go`, `internal/config/`, `internal/store/` (db.go, migrations/*.sql), `internal/crypto/signer/` (signer.go, software.go), `internal/server/server.go`.
- `config.Load(path string) (*Config, error)`: YAML + `CONRAD_*` env.
- `store.Open(path string) (*Store, error)`: WAL, migrations applied on open.
- `signer.Provider` with `Generate(alg) (KeyRef, crypto.Signer, error)` and `Load(KeyRef) (crypto.Signer, error)`. The software provider uses AES-GCM + argon2id and keeps the passphrase in memory once unlocked.
- Server serves `/healthz` and `/readyz`.
Verify: `go test ./internal/...`

## M2: CA
Files: `internal/ca/` (authority.go, issue.go, revoke.go, crl.go, ocsp.go, rotate.go, mobileconfig.go), store repos `authorities.go`, `certificates.go`.
- `ca.Service`: `InitRoot`, `CreateIssuer`, `Issue(ctx, issuerSlug, csr, opts)`, `Revoke`, `RotateIssuer`, `RevokeIssuer`, `CRL(slug)`, `OCSPHandler`, `Unlock(passphrase)`.
- Endpoints: `/roots/root.pem|.crt|.mobileconfig`, `/crl/{slug}.crl`, `/ocsp/{slug}`.
Verify: unit tests for the chain (root → issuer → leaf), CRL contents, OCSP good/revoked, rotation.

## M3: ACME
Files: `internal/policy/`, `internal/acme/` (handlers per resource, jws.go, nonce.go, eab.go, problem.go, ari.go), `internal/challenge/` (http01.go, dns01.go, tlsalpn01.go, worker.go).
- Verify: integration test with lego in-process (HTTP-01, DNS-01 with a miekg/dns fake, TLS-ALPN-01), issuer isolation, EAB, revoke, key rollover.

## M4: Auth, API, audit
Files: `internal/auth/` (password.go, session.go, csrf.go, oidc.go, ratelimit.go), `internal/audit/`, `internal/api/` (one file per resource), `internal/web/embed.go`.
- Setup token printed on first boot; `/api/v1/setup` works only while no admin exists.
Verify: API tests with httptest for setup, login, CSRF rejection, authorities CRUD, certificates list/revoke.

## M5: Notifications
Files: `internal/notify/` (scheduler.go, smtp.go, webhook.go, templates/{en,it}/*.tmpl).
- SMTP modes `none|starttls|tls`, optional AUTH; webhook HMAC; dedupe through `notification_log`.
Verify: tests against an in-process SMTP mock and an httptest webhook receiver.

## M6: Web UI
Files: `web/` (Vite app), `web/src/styles/tokens.css`, `web/src/locales/{en,it}/*.json`, `web/src/components/brand/Logo.tsx`, pages: Setup, Login, Dashboard, Authorities, Certificates, Accounts, InstallCA, AcmeClients, Notifications, Settings.
- Design with the ui-ux-pro-max and ui-styling skills, using the palette and logo from the spec.
Verify: `pnpm build`, `pnpm test` (Vitest + locale parity test), Playwright smoke test of the wizard and issuance.

## M7: PKCS#11, packaging, docs
Files: `internal/crypto/signer/pkcs11.go` (`//go:build pkcs11`), `deploy/Dockerfile`, `deploy/Dockerfile.pkcs11`, `deploy/docker-compose.yml`, `deploy/conrad.service`, `.goreleaser.yaml`, `.github/workflows/ci.yml` (Go + web + certbot + SoftHSM jobs), `README.md`, `docs/*.md`.
Verify: `docker build` succeeds; the certbot job in CI obtains a certificate.
